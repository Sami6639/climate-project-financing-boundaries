# Computational supplement

Companion to *Advance Finance and Exposure Limits in Emissions-Linked Funding: An Analytical Framework Illustrated by UEFA EURO 2024*.

## Run

Use Python 3.12 and install the versions in `requirements.txt`, then run:

    python code/reproduce.py

The command resolves all paths relative to this package and writes tables, figures, verification records and runtime information into `results/`. It does not require online access. No random sampling is used, so a random seed is not applicable. The included `results/runtime.json` gives the measured runtime and dependency versions in the execution environment used to prepare the manuscript. Allow additional time on slower machines.

## Scope and evidence

This package reproduces analytical scenarios, not an empirical estimate of the EURO 2024 reporting process or recipient financing needs. The documentary anchors are the reported inventory, announced fund, reported investment, nominal pledge and separate recipient accounts. Relative reporting dispersion, target marginal obligation, donor cap, financing loading and aggregate advance are assumptions.

This is the reproducible implementation accompanying the 7 October 2026 manuscript revision. Its numerical audit records are generated by the included code. The earlier public analysis is preserved at https://github.com/Sami6639/uefa-euro2024-carbon-linked-finance/tree/4811387251b118b2fbfa6bca9076bc454c54c233. Its output numbering and computational grids differ from this revision and should not be mixed with the present results.

Tables 1 and 4 are documentary registers; they are not generated from an individual-level dataset. Table A1 is a literature comparison, not a claim of exhaustive theoretical priority.

## Numerical interpretation

Uniform LPs use a free baseline and piecewise-constant slopes on [-1,1], bounded between zero and one. The mean and objective integrals are exact for that discretised class. The cap applies globally, including constant tails. No ramp is imposed on the LP. Gaussian LPs use analytically integrated probability and mean weights on [-12,12] standard deviations, with constant tails. Those restricted classes provide lower approximations to the analytic optima. The mathematical proofs establish existence and optimality; grid agreement is an implementation diagnostic.
